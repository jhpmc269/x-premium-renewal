## 续费时想换档：升级和降级怎么算钱

续费前顺手换个档位是常见操作，但三个平台的结算方式不一样，搞混了容易多花钱。

**网页端**：升级时，当前周期剩余额度直接抵扣新档费用，补上差价立即生效，账单按新档的周期重新走。降级则要等当前周期结束才切换，剩余时间不退钱，法律另有要求的除外。

**iOS**：升级会按剩余时间比例退还旧档的费用；降级同样是周期结束后切换到新档，然后按新价格开始扣。

**Android（Google Play）**：升级立即生效，剩余时间按比例折算成抵扣；降级也是马上切到新档，但下次扣费日期会按旧档剩余价值顺延，等于把没用的部分折成了时间还给你。

简单概括：网页端升级最干脆，安卓的折算机制最灵活，iOS的退款只发生在升级场景。另外，同一天内升级不会影响创作者分成收益的结算。

## 续费常见问题

### 扣费金额和当初订阅时不一样，正常吗？

正常。只要你的续费周期开始于2025年3月22日之后，扣的就是调价后的新价格，详见上面的价格表。

### App内续费为什么比网页贵？

应用商店抽成导致的。官方明确表示网页端是最低价，下一期不妨换到网页端续。

### 忘了取消被自动扣款，能退吗？

按官方规则，除非当地法律另有要求，订阅费用原则上不退，账号被封禁的情况下同样不退。App Store和Google Play的订阅退款要分别向苹果、谷歌提出申请。

### 取消续费后蓝标马上消失吗？

不会。蓝标保留到已付费周期结束，之后才随订阅一起失效。

### 续费了但部分功能没生效？

先对照官方功能列表确认该权益属于哪个档位，再走官方的故障排查步骤。蓝标本身要经过资格审核，新审核可能需要几个工作日。确认权益缺失的情况下再联系官方支持。

### 换了头像、昵称或用户名，蓝标没了，是续费的问题吗？

不是。资料变更会触发账号重新审核，审核通过前蓝标暂时隐藏，期间也不能继续改资料。这和续费状态是两回事。
